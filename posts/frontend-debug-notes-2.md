# 一次前端调试复盘 2

这篇是第二篇调试日记，用来确认新增文章、标签筛选和 Python 接口都能正常工作。

## 问题现象

页面提示文章加载失败，但浏览器里能看到首页样式，说明静态文件大概率已经返回了，问题更可能出在文章列表接口或文章文件路径上。

## 排查路径

- 先访问 `/api/posts`，确认接口是否返回 JSON 数组
- 再检查 `posts.json` 是否是合法 JSON
- 最后检查每篇文章的 `file` 路径是否真实存在

## 解决方案

让前端优先使用 Python 后台接口；如果接口不存在，就自动退回到静态文件读取。这样本地开发和 GitHub Pages 部署都能使用同一套前端。

```js
const posts = await loadPosts();
```

## 收获

后台重构以后，最容易出错的不是页面样式，而是数据接口的返回格式。只要接口和前端约定稳定，页面就会稳很多。
