# 一次前端调试复盘

这篇文章展示一种适合技术博客的写法：先写现象，再写定位路径，最后写结论和经验。

## 问题现象

页面加载后列表为空，但接口返回的数据是正常的。刷新几次后偶尔又能显示。

## 排查路径

- 先确认接口返回值，排除后端数据问题
- 再检查渲染条件，发现组件在数据到达前提前进入空状态
- 最后定位到状态更新顺序不稳定

## 解决方案

把加载状态、空状态、错误状态拆开处理，避免用一个布尔值表达所有状态。

```js
const viewState = loading ? "loading" : error ? "error" : list.length ? "ready" : "empty";
```

## 收获

调试时不要只看最终结果，更要看状态转换过程。很多前端问题，本质上都是状态边界没有表达清楚。
